Using Studio

The current artist workspace is a public foundation.

What you can use

You can browse workspace explanations and follow guidance. There are no private accounts, authenticated sessions, artist-specific statistics or stored agreements.

What not to enter

Do not enter passwords, signatures, private contracts or financial details into a public page. Future operational features require a secure backend and access controls.
