Public technical foundation

How the three public surfaces are built.

One shared foundation

The main label repository owns the shared Artanrecords foundation. Docs and Studio consume committed, checksum-verified snapshots of its approved assets and renderer.

Content and rendering

Each surface owns its content/site.json. Static HTML, page metadata and sitemap are generated from that collection. CSS controls presentation and JavaScript progressively enhances navigation, theme and documentation search.

Build and checks

Use Node 22 or later. Run npm run build and npm run check. Shared changes belong in the main repository and are synchronized deliberately; do not patch copied token or icon files.

Public only

GitHub Pages serves public files. It is not the authorization boundary for private artist data. No private information, credentials, financial records or internal business specification belongs in these repositories.
